# Roadmap
1. Backend (Firebase or Node+Postgres): auth, users, alerts, messages, evidence upload, live tracking, police dashboard auth.
2. Android app (Kotlin): shake foreground service, SMS, direct calling, CameraX recording during calls, WebRTC voice with police.
3. Wear OS app: SOS button, phone-separation alert.
4. AI service: real threat detection (weapon, running) on video/sensor data.
5. Live events feed from a real source.
6. Legal: police partnership, false-alarm controls, privacy and consent.
